# LectureNotes

Android-приложение для записи и конспектирования лекций: записывает аудио, распознаёт речь через Groq Whisper и превращает текст в структурированный конспект с помощью Gemini.

## Возможности

- **Список конспектов** — заголовок, дата, категория.
- **Создание конспекта** — через диалог (название + категория).
- **Экран конспекта**:
  - запись лекции через микрофон (MediaRecorder) или загрузка готового аудиофайла;
  - прослушивание записанного/загруженного аудио;
  - распознавание речи — аудио отправляется в Groq (Whisper large-v3-turbo, язык — русский), результат сохраняется;
  - редактирование текста лекции вручную с автосохранением;
  - генерация конспекта — текст отправляется в Gemini (gemini-2.0-flash) с промптом на структурирование;
  - редактирование конспекта вручную с автосохранением.
- **Настройки** — ввод собственных API-ключей Groq и Gemini (хранятся локально в SharedPreferences).
- **Локальное хранение** — база Room, аудиофайлы во внутреннем хранилище приложения.

## Требования

- Android Studio (актуальная версия)
- Android SDK, минимальная версия — согласно `build.gradle`
- Аккаунт Groq и Google AI Studio для получения API-ключей (оба бесплатны, без привязки карты)

## Установка и запуск

1. Откройте папку `LectureNotes` в Android Studio: **File → Open**.
2. Дождитесь синхронизации Gradle. Если появится предложение обновить Gradle Wrapper — согласитесь, он подтянет актуальную версию.
3. Получите API-ключи:
   - **Groq**: [console.groq.com](https://console.groq.com) → API Keys → создать ключ.
   - **Gemini**: [aistudio.google.com](https://aistudio.google.com) → Get API key.
4. Запустите приложение на эмуляторе или устройстве.
5. Откройте настройки (шестерёнка в тулбаре) и вставьте оба ключа.
6. Создайте конспект, запишите или загрузите аудио, нажмите **«Распознать текст»**, затем **«Сделать конспект»**.

## Структура проекта

## Как это работает

1. **Запись или загрузка аудио.** MediaRecorder пишет лекцию, либо вы выбираете готовый файл. Аудио сохраняется во внутреннем хранилище приложения.
2. **Распознавание речи.** Файл отправляется в Groq Whisper large-v3-turbo с указанием языка (русский). Полученный текст сохраняется в заметку.
3. **Генерация конспекта.** Текст лекции уходит в Gemini с промптом на структурирование. Результат сохраняется отдельно и доступен для ручной правки.
