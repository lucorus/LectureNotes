# Конспекты лекций — Android приложение

## Что уже сделано (MVP)

- Список конспектов (заголовок, дата, категория) — экран `MainActivity`
- Создание нового конспекта через диалог (название + категория)
- На экране конспекта (`NoteDetailActivity`):
  - запись лекции через микрофон (MediaRecorder) **или** загрузка готового аудиофайла
  - прослушивание записанного/загруженного аудио
  - кнопка «Распознать текст» — отправляет аудио в Groq (Whisper large-v3-turbo, язык явно указан как русский) и сохраняет результат
  - текст лекции редактируется вручную, сохраняется автоматически при изменении
  - кнопка «Сделать конспект» — отправляет текст в Gemini (gemini-2.0-flash) с промптом на структурирование конспекта
  - конспект тоже редактируется вручную и сохраняется автоматически
- Экран настроек — куда вписать свои API-ключи Groq и Gemini (хранятся локально на устройстве в SharedPreferences)
- Всё хранится локально в базе Room, аудиофайлы — во внутреннем хранилище приложения

## Как запустить

1. Открой папку `LectureNotes` в Android Studio (File → Open).
2. Дай Android Studio синхронизировать Gradle (если попросит обновить Gradle Wrapper — соглашайся, он подтянет актуальную версию сам).
3. Получи ключи:
   - **Groq**: console.groq.com → API Keys → создать ключ (бесплатно, без карты)
   - **Gemini**: aistudio.google.com → Get API key (бесплатно, без карты)
4. Запусти приложение на эмуляторе или телефоне, зайди в настройки (шестерёнка в тулбаре) и вставь оба ключа.
5. Создай конспект, запиши/загрузи аудио, нажми «Распознать текст», затем «Сделать конспект».

## Что стоит доработать дальше (по желанию)

- **Долгие лекции**: Groq принимает файл целиком, но есть лимиты по размеру — для лекций дольше ~40-50 минут может понадобиться нарезка аудио на куски перед отправкой и склейка текста после. Пока это не реализовано — для начала стоит проверить, как ведёт себя реальная лекция.
- **Индикатор прогресса записи**: сейчас кнопка просто меняет текст на «Остановить запись», можно добавить таймер.
- **Удаление конспектов**: сейчас нет свайпа/кнопки удаления в списке — легко добавить через `ItemTouchHelper` или долгое нажатие.
- **Разные модели Gemini**: если `gemini-2.0-flash` перестанет быть актуальным именем модели, замени строку в `LectureAiHelper.kt` на актуальную (можно посмотреть в Google AI Studio, там показывает доступные модели).
- **Хранение ключей**: сейчас ключи лежат в обычных SharedPreferences — для собственного использования это ок, но для публикации в Play Store стоило бы использовать EncryptedSharedPreferences.

## Структура проекта

```
app/src/main/java/com/example/lecturenotes/
├── data/            — Room: Note (сущность), NoteDao, AppDatabase, NoteRepository
├── network/          — Retrofit-интерфейсы Groq/Gemini, ApiKeyStore, LectureAiHelper (логика запросов)
└── ui/               — MainActivity, NoteDetailActivity, SettingsActivity, NoteAdapter
```
